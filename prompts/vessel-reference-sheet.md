## The Prompt

Create a professional vessel reference sheet based strictly on the supplied yacht reference images. Present the yacht on a clean neutral light grey background as a technical marine model turnaround sheet. Match the exact proportions, hull geometry, superstructure design, window shapes, radar mast arrangement, deck layouts, and overall visual appearance of the reference yacht.

Arrange the composition into two horizontal rows.

Top Row — four full-vessel orthographic views aligned side-by-side: 1. Port profile 2. Bow elevation (front view) 3. Starboard profile 4. Stern elevation (rear view). Ensure all views are perfectly aligned to the same scale, with matching waterline position, deck heights, and mast height. Maintain precise geometry consistency between every view.

Bottom Row — three detailed perspective hero views: 1. Front three-quarter port view 2. Rear three-quarter starboard view 3. Top-down aerial plan view. Maintain exact vessel identity and proportions across all panels.

Show: bow shape, anchor pockets, hull windows, bridge glazing, radar domes, mast structure, foredeck layout, jacuzzi placement, beach club configuration, tender positions.

Lighting should be neutral studio lighting with soft shadows and consistent illumination across all panels. No dramatic mood lighting. No ocean background. No scenery.

Output as a clean technical marine reference sheet suitable for professional storyboarding, concept design, VFX continuity, image generation, and commercial production planning. Ultra-sharp details, print-ready presentation, consistent scale, architectural accuracy.
